# قائمة تجهيز المصنع قبل بدء التشغيل — Qema ERP

قائمة مختصرة لصاحب المصنع. ضع علامة ✓ عند إنهاء كل بند. التفاصيل في `docs/USER_GUIDE_AR.md`.

## قبل أي شيء (مع مسؤول النظام)
- [ ] تأكد أن مسؤول النظام جهّز قاعدة المصنع النظيفة: تطبيق الترحيلات ثم `scripts/bootstrap_factory_db.py` (الأدوار والمخازن الثلاثة دون أي بيانات تجريبية) وإسناد الأدوار لحسابات الموظفين.
- [ ] راجع قائمة المستخدمين: لكل موظف حساب بالبريد وكلمة مرور، ودور واحد من الأربعة: المدير العام، أمين المخزن، مسؤول الإنتاج، المدير المالي. (لا توجد شاشة لإدارة المستخدمين؛ مسؤول النظام يسند الأدوار.)
- [ ] اعرف أن مستندات المدير المالي تُعتمد لحظة حفظها (لا جهة اعتماد فوقه)؛ راجع المبلغ قبل الحفظ، والخطأ يُصحح بمستند عكسي.
- [ ] قرّر من يعتمد ما ينشئه المدير العام بنفسه في الجرد ودليل الأصناف، أو اترك الإنشاء لأمين المخزن.

## البيانات الأساسية
- [ ] **التصنيفات:** أضف التصنيفات الرئيسية والفرعية في «دليل الخامات والأصناف ← شجرة التصنيفات». (أمين المخزن)
- [ ] **الأصناف:** أضف كل خامة ومستلزم بكوده ووحدته وتصنيفه، وقدّمه للاعتماد. (أمين المخزن)
- [ ] **اعتماد الأصناف:** اعتمد الأصناف المقدمة. تأكد أن الأصناف المطلوبة للإنتاج عليها علامة «يصلح للمستلزمات». (المدير العام)
- [ ] **الوحدات:** راجع أن الوحدات الموجودة تكفي أصنافك (لا يمكن إضافة وحدة من الواجهة).
- [ ] **الموردون:** أضفهم من البيانات الأساسية. (أمين المخزن أو المدير المالي)
- [ ] **العملاء:** أضفهم من البيانات الأساسية أو «العملاء والطلبات». (المدير المالي)
- [ ] **الموديلات والمقاسات:** أضف كل موديل ومقاساته ومواسمها. (مسؤول الإنتاج)
- [ ] **مستلزمات التصنيع:** عرّف مستلزمات كل مقاس نشط حتى يختفي تنبيه «مقاس بدون مستلزمات». استخدم «نسخ من مقاس آخر» ثم عدّل الكميات. (مسؤول الإنتاج)
- [ ] **الموظفون:** أضفهم مع نظام الأجر (شهري أو يومية) والقيمة. (المدير المالي)

## الأرصدة الافتتاحية (بالطريقة الموجودة في النظام فقط)
- [ ] **المخزون:** افتح جلسة جرد كامل لكل مخزن، وعدّ الموجود فعلياً، وارفعه للاعتماد. (أمين المخزن)
- [ ] اعتمد الجرد ورحّل التسويات. لا تُجرِ أي استلام أو صرف على الأصناف قبل الترحيل. (المدير العام)
- [ ] **الخزنة:** عدّ النقدية الفعلية، وسجّل سند قبض على الخزنة الرئيسية بوصف «رصيد افتتاحي». يُعتمد فوراً. (المدير المالي)
- [ ] راجع شاشة «الخزينة والاعتمادات» وأرصدة المخازن بعد الترحيل.

## تحديد المسؤوليات
- [ ] من يسجل فواتير الشراء ويستلم الخامات؟ (أمين المخزن)
- [ ] من ينشئ أوامر التشغيل ويؤكد استلام الخامات بالورشة؟ (مسؤول الإنتاج)
- [ ] من يصرف الخامات ويستلم المنتج التام ويسلّم العملاء؟ (أمين المخزن)
- [ ] من يسجل طلبات البيع والتحصيلات ويعد الرواتب؟ (المدير المالي)
- [ ] السندات والتحصيلات وكشوف الرواتب: يسجلها المدير المالي وتُعتمد عند الحفظ؛ وهو من يعتمد طلبات السداد القادمة من أمين المخزن.
- [ ] من يعتمد الجرد والأصناف الجديدة؟ (المدير العام)

## تجربة قبل التشغيل الفعلي
- [ ] نفّذ دورة صغيرة كاملة: فاتورة شراء ← استلام ← أمر تشغيل صغير ← صرف ← تأكيد الورشة ← المراحل ← استلام المنتج التام ← تسوية وإغلاق ← طلب عميل ← تسليم ← تحصيل ← اعتماد.
- [ ] راجع التقارير: حركة الخزينة، مديونيات العملاء، مستحقات الموردين، أرصدة المخازن.

## التدريب
- [ ] درّب كل موظف على فصل دوره في دليل الاستخدام، وعلى «الرئيسية · مهامي».
- [ ] اشرح للجميع: «مطلوب منك الآن» للتنفيذ، «بانتظار الآخرين» للمتابعة فقط.
- [ ] اقرأ مع الإدارة «القيود المعروفة» وقرّر البنود المعلقة في القسم «ب».

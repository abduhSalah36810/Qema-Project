# قائمة تجهيز المصنع قبل بدء التشغيل — Qema ERP

قائمة مختصرة لصاحب المصنع. ضع علامة ✓ عند إنهاء كل بند. التفاصيل في `docs/USER_GUIDE_AR.md`.

## قبل أي شيء (مع مسؤول النظام)
- [ ] تأكد أن مسؤول النظام جهّز قاعدة المصنع النظيفة: تطبيق الترحيلات ثم `scripts/bootstrap_factory_db.py` (الأدوار والمخازن الثلاثة دون أي بيانات تجريبية) وإسناد الأدوار لحسابات الموظفين.
- [ ] راجع قائمة المستخدمين: لكل موظف حساب بالبريد وكلمة مرور، ودور واحد من الأربعة: المدير العام، أمين المخزن، مسؤول الإنتاج، المدير المالي. (لا توجد شاشة لإدارة المستخدمين؛ مسؤول النظام يسند الأدوار.)
- [ ] اعرف أن مستندات المدير المالي النقدية تُرحَّل فوراً بقرار FIN-DEC-01 دون معتمد ثانٍ (بما فيها سداد الموردين والدفع المقدم)، ومنع الاعتماد الذاتي يسري على المستندات المعلقة لغيره، ومستندات الرواتب، والمستندات الافتتاحية، والمخزون. راجع المبلغ قبل الحفظ، والخطأ يُصحح بمستند عكسي؛ والضابط التعويضي هو مراجعة لاحقة من المدير العام.
- [x] معتمد الجرد والأصناف: المدير المالي (أمين المخزن ينشئ ويعدّ).

## البيانات الأساسية
- [ ] **التصنيفات:** أضف التصنيفات الرئيسية والفرعية في «دليل الخامات والأصناف ← شجرة التصنيفات». (أمين المخزن)
- [ ] **الأصناف:** أضف كل خامة ومستلزم بكوده ووحدته وتصنيفه، وقدّمه للاعتماد. (أمين المخزن)
- [ ] **اعتماد الأصناف:** اعتمد الأصناف المقدمة. تأكد أن الأصناف المطلوبة للإنتاج عليها علامة «يصلح للمستلزمات». (المدير العام)
- [ ] **الوحدات:** راجع أن الوحدات الموجودة تكفي أصنافك (يضيف أمين المخازن أي وحدة ناقصة من دليل الأصناف ← تبويب «وحدات القياس»).
- [ ] **الموردون:** أضفهم من البيانات الأساسية. (أمين المخزن أو المدير المالي)
- [ ] **العملاء:** أضفهم من البيانات الأساسية أو «العملاء والطلبات». (المدير المالي)
- [ ] **الموديلات والمقاسات:** أضف كل موديل ومقاساته ومواسمها. (مسؤول الإنتاج)
- [ ] **مستلزمات التصنيع:** عرّف مستلزمات كل مقاس نشط حتى يختفي تنبيه «مقاس بدون مستلزمات». استخدم «نسخ من مقاس آخر» ثم عدّل الكميات. (مسؤول الإنتاج)
- [ ] **الموظفون:** أضفهم مع نظام الأجر (شهري أو يومية) والقيمة. (المدير المالي)

## الأرصدة الافتتاحية ويوم القطع (Day-0 Cutover)
- [ ] **المخزون الافتتاحي:** افتح جلسة جرد باختيار خانة «جرد افتتاحي» لكل مخزن، وسجّل الكميات الفعلية مع **تكلفة الوحدة الإلزامية** لكل خامة، وارفعه للاعتماد. (أمين المخزن)
- [ ] **اعتماد الجرد الافتتاحي:** اعتمد الجرد لترحيل القيود لحساب 3900 دون التأثير على حسابات الفروقات. (المدير العام)
- [ ] **فواتير الموردين الافتتاحية:** سجّل الفواتير غير المسددة عبر زر «＋ إدخال رصيد افتتاحي لمورد» برقم وتاريخ الفاتورة الأصلية. (المدير المالي)
- [ ] **اعتماد فواتير الموردين:** اعتمد الفواتير الافتتاحية لتظهر في كشف حساب المورد بوسم «رصيد افتتاحي». (المدير العام)
- [ ] **أرصدة العملاء الافتتاحية:** سجّل المديونيات السابقة من شاشة حساب العميل برقم الطلب والتاريخ. (المدير المالي)
- [ ] **اعتماد أرصدة العملاء:** اعتمد الرصيد الافتتاحي ليظهر في كشف حسابه. (المدير العام)
- [ ] **القيد الافتتاحي العام وقفل الأرصدة:** سجّل رصيد الخزينة، رصيد البنك، ورأس المال المدفوع وتاريخ البدء من شاشة «الميزانية العمومية»، ثم أكّد ترحيله لإقفال الأرصدة الافتتاحية نهائياً. (المدير المالي)
- [ ] **التحقق من الخزينة ودفتر النقدية (إصلاح DEFECT-DAY0-01):** تحقق من ظهور الرصيد الافتتاحي في كشف حساب النقدية وتطابق دفتر النقدية مع الأستاذ العام، وإمكانية سداد الموردين فوراً.

## تجربة قبل التشغيل الفعلي
- [ ] نفّذ دورة صغيرة كاملة: فاتورة شراء ← استلام ← أمر تشغيل صغير ← صرف ← تأكيد الورشة ← المراحل ← استلام المنتج التام ← تسوية وإغلاق ← طلب عميل ← تسليم ← تحصيل ← اعتماد.
- [ ] راجع التقارير: حركة الخزينة، مديونيات العملاء، مستحقات الموردين، أرصدة المخازن.

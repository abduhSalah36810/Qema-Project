## 1. ملخص التصميم وتجربة المستخدم (Design & UX Summary)

تم تنفيذ واجهة إدارة دليل الأصناف والتصنيفات (Catalog Management Frontend) وفق معايير Qema ERP، باتجاه تصميم مخصص للمصنع (Custom Factory-Oriented Product Design)، بعيداً عن قوالب لوحات التحكم الجاهزة (Generic Admin Templates).

### أبرز ملامح التصميم:
1. **هوية بصرية متناسقة (Cohesive Brand Identity):**
   - الالتزام التام بنظام التصميم المعتمد في `styles/index.css`، باستخدام لوحة ألوان رسمية وقورة: الكحلي الداكن للشريط الجانبي (`#0f172a`)، والتيل البترولي للإجراءات الرئيسية (`#0f766e`)، والأرضية الدافئة المريحة للعين (`#f4f5f7`)، والبطاقات البيضاء الناصعة (`#ffffff`).
   - دعم عربي RTL أصيل مع ضبط كامل للاتجاهات، الهوامش، الأيقونات، وحقول الأكواد الإنجليزية (`ltr`).
2. **شريط مؤشرات ملخص غير مزدحم (Clean KPI Overview):**
   - عرض 4 مؤشرات حيوية مستمدة من البيانات الفعلية لقاعدة البيانات: إجمالي أصناف الدليل، الأصناف المعتمدة، الأصناف قيد المراجعة، والتصنيفات النشطة.
3. **تنظيم التبويبات المتخصصة (Sub-Navigation Tabs):**
   - تقسيم مهام إدارة الدليل إلى 4 شاشات متخصصة دون ازدحام:
     - **دليل الأصناف (Items Catalog):** جدول عملي وقابل للبحث والتصفية متعددة الأبعاد.
     - **شجرة التصنيفات (Categories Explorer):** مستكشف هرمي للفئات الرئيسية والفرعية مع خيارات التوسيع والطي والتحكم في التفعيل.
     - **خطوط الاستخدام (Application Lines):** بطاقات تعريفية للخطوط الستة مع إمكانية التصفية المباشرة.
     - **دليل الوحدات المرجعي (Units Reference):** جدول مرجعي للقراءة فقط يوضح سياسة منع التحويلات التلقائية.
4. **بطاقة منزلقة لتفاصيل الصنف (Item Detail Drawer):**
   - استعراض وتعديل بيانات الصنف في لوحة منزلقة سلسة تنفتح من جانب الشاشة، تتضمن المواصفات الفنية (JSONB Attributes) مثل العرض والوزن والقطر، وحد إعادة الطلب، ووسوم خطوط الاستخدام.

## 2. الشاشات المنفذة وتفاصيلها (Implemented Views)

### أ. نظرة عامة ومؤشرات الدليل (Catalog Overview & KPIs)
- **الموقع:** أعلى صفحة الدليل (`CatalogOverviewKPIs.tsx`).
- **المحتوى:**
  - `إجمالي أصناف الدليل`: عدد الأصناف الكلي في قاعدة البيانات.
  - `أصناف معتمدة وموثقة (Confirmed)`: الأصناف التي تم اعتماد مطابقتها القياسية.
  - `أصناف قيد المراجعة (Needs Review)`: الأصناف التي تنتظر استكمال شيتات المصنع أو اعتماد الإدارة.
  - `التصنيفات النشطة`: عدد الفئات المتاحة للاختيار في العمليات.

### ب. جدول دليل الأصناف (Items Catalog Table)
- **الموقع:** التبويب الأول (`CatalogItemsTable.tsx`).
- **المزايا:**
  - **بحث سريع:** يطابق كود الصنف أو اسمه بالعربية.
  - **فلترة متعددة الأبعاد:**
    - حسب التصنيف الهرمي (Category).
    - حسب نوع الصنف (قماش، إكسسوارات، صيانة، أدوات، تعبئة، منتجات تامة).
    - حسب حالة المراجعة (`confirmed`, `suggested`, `needs_review`, `not_applicable`).
    - حسب وحدة القياس.
  - **أعمدة الجدول:** كود الصنف (بخط رمزي)، اسم الصنف بالعربية، التصنيف، النوع، الوحدة، شارة الاعتماد (Classification Badge)، حد إعادة الطلب، والإجراءات.
  - **حالات العرض:** حالة التحميل المتحركة، حالة الفراغ الإرشادية (Empty State)، وتنبيهات الأخطاء مع زر إعادة المحاولة.
  - **الترقيم والتنقل (Pagination):** دعم الانتقال بين الصفحات مع الحفاظ على الفلاتر النشطة.

### ج. بطاقة تفاصيل الصنف (Item Detail Drawer)
- **الموقع:** لوحة جانبية تنبثق عند الضغط على "عرض وتعديل" لأي صنف (`ItemDetailDrawer.tsx`).
- **المجموعات المنظمة:**
  1. **البيانات الأساسية:** كود الصنف، الاسم بالعربية، النوع، الوحدة، التصنيف الأب، حالة الصنف (مستهلك أم لا)، وتفعيل الصنف.
  2. **حالة الاعتماد وحد الطلب:** اختيار حالة المراجعة، وتحديد حد إعادة الطلب مع بيان أن القيمة صفر تعني عدم تفعيل التنبيه.
  3. **المواصفات الفنية (JSONB Attributes):** مدخلات قياسية للأبعاد (`width_cm`, `weight_gsm`, `length_cm`, `diameter_mm`).
  4. **وسوم خطوط الاستخدام (Application Usages):** استعراض الخطوط المرتبطة، مع إمكانية ربط خط جديد أو حذفه فوريًا.
  5. **حماية المنتجات التامة (FG-VAR-* Protection):** تنبيه خاص يوضح أن الأصناف التامة محمية وتتبع الموديلات، وحظر تعديل وحدتها أو تصنيفها، وإخفاء زر الحذف.

### د. مستكشف شجرة التصنيفات (Categories Explorer)
- **الموقع:** التبويب الثاني (`CategoriesExplorer.tsx`).
- **المزايا:**
  - عرض الفئات الرئيسية العشر المعيارية مع تمييزها بشارة "معياري".
  - فتح وإغلاق الفئات الفرعية (39 فئة فرعية).
  - إمكانية "توسيع الكل" أو "طي الكل" بضغطة زر.
  - زر مباشر "عرض الأصناف" ينقل المستخدم فوراً إلى تبويب الأصناف مع تطبيق فلتر هذا التصنيف.
  - إضافة تصنيف فرعي داخل أي فئة رئيسية أو إضافة تصنيف رئيسي جديد.
  - تعديل بيانات التصنيف (الاسم العربي، الاسم الإنجليزي، الوصف، التصنيف الأب، ترتيب العرض، والتفعيل).
  - حماية منع الحلقات التكرارية (Cycle Prevention) ومنع اختيار التصنيف كأب لنفسه.
  - حظر حذف التصنيفات المعيارية، وعرض رسائل خطأ ودية عند تعذر حذف تصنيف مخصص مرتبط بأصناف.

### هـ. خطوط الاستخدام (Application Lines)
- **الموقع:** التبويب الثالث (`ApplicationLinesView.tsx`).
- **المحتوى:**
  - استعراض الخطوط الستة المعتمدة: `GENERAL`, `JALABIYA`, `MOROCCAN_JALABIYA`, `SHERWAL`, `THOBE_ARABI`, `BOYS_CLOTHING`.
  - أيقونات تعبيرية وهوامش توضيحية لكل خط.
  - إشعار تنظيمي يؤكد أن وسوم الاستخدام لا تمثل BOM أو تكاليف إنتاج.
  - زر لتصفية دليل الأصناف لعرض المواد المرتبطة بخط إنتاج معين.

### و. دليل الوحدات المرجعي (Units Reference)
- **الموقع:** التبويب الرابع (`UnitsReferenceView.tsx`).
- **المحتوى:**
  - جدول مرجعي للقراءة فقط لجميع الوحدات التسع المعتمدة (`piece`, `meter`, `kg`, `gram`, `roll`, `box`, `pack`, `carton`, `pair`).
  - توضيح استخدام كل وحدة وأمثلتها العملية داخل المصنع.
  - تنبيه يوضح سياسة القياس المعتمدة لمنع التحويلات التلقائية العشوائية في موازين المخازن.

### ز. نافذة إضافة صنف جديد (Item Create Modal)
- **الموقع:** نافذة منبثقة (`ItemCreateModal.tsx`).
- **المزايا:**
  - إدخال الكود، الاسم، النوع، الوحدة، التصنيف، حالة المراجعة، الأبعاد، وحد الطلب.
  - **حظر إنشاء المنتجات التامة:** رفض أي كود يبدأ بـ `FG-*` مع إظهار رسالة إرشادية للمستخدم بأن المنتجات التامة تنشأ تلقائياً من شاشة الموديلات.
  - التحقق الفوري من الحقول الإلزامية قبل الإرسال.

## 5. تكامل الـ API وقواعد الأعمال (API Integration & Business Rules)

تم ربط الواجهة مباشرة مع الـ APIs المنفذة في Phase 3.2 عبر المسار المعتمد `/api/v1/catalog`:

1. **حماية المنتجات التامة (FG Protection):**
   - منع إنشاء الأصناف التي تبدأ بـ `FG-*` من الواجهة العامة.
   - حظر تعديل تصنيف أو وحدة أو اسم المنتجات التامة عند فتح بطاقتها، وإخفاء زر الحذف، مع عرض شارة واضحة وتنبيه إرشادي.
2. **شجرة التصنيفات ومنع الحلقات (Cycle Prevention):**
   - حظر اختيار التصنيف كأب لنفسه في النموذج.
   - حظر حذف التصنيفات المعيارية المنشأة في Migration 0011 في الواجهة والـ API.
3. **المواصفات الفنية (Attributes JSONB):**
   - تنظيم الأبعاد المشهورة (`width_cm`, `weight_gsm`, `length_cm`, `diameter_mm`) كأرقام موجبة.
4. **حد إعادة الطلب (Reorder Level):**
   - قيد أن يكون رقماً غير سالب، مع توضيح أن 0 يعني عدم تفعيل التنبيه.
5. **خطوط الاستخدام (Application Usages):**
   - إضافة وحذف الروابط كمعلومات تنظيمية عبر `/usages` دون المساس بحسابات BOM أو التكاليف.
6. **وحدات القياس (Units):**
   - واجهة قراءة فقط (Read-Only) تمنع أي تحويلات تلقائية مضللة.
